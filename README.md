# 墨隐 Moyin · 多语种文本隐私脱敏

面向大模型分析场景的中英混合文本隐私识别与可控脱敏系统。文本先经过“规则 → NER → 大模型核查”三层识别，再按掩码、差分隐私替换或知识图谱泛化处理；人工复核、最终稿编辑和导出前复检都在同一个工作台里完成。不连接任何模型时也能运行完整流程。

蓝本为《立项书》与两份“附件5”申报书。逐项对照见 [立项功能对照检查.md](立项功能对照检查.md)，测试记录见 [TESTING_20261003.md](TESTING_20261003.md)（上一轮：[TESTING_20261002.md](TESTING_20261002.md)）。

## 快速开始（Windows 本机）

需要 Python 3.11+ 和 Node.js 20.19+（或 22.12+）。

```powershell
# 后端（第一次运行先建虚拟环境）
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000

# 前端（另开一个终端；依赖有更新，第一次要先 npm install）
cd frontend
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>，第一次打开会先进入“上手指南”。更省事的做法是双击项目根目录的 `启动墨隐.cmd`：它会检查 Node.js 版本、在需要时安装前后端依赖，然后各开一个窗口运行后端和前端，并打开浏览器；关掉这两个窗口即停止。接口文档在 <http://127.0.0.1:8000/api/docs>。

## 界面与功能

左侧导航按使用顺序分组：处理文本（工作台、批量处理、人工复核）、配置（项目、规则库）、记录与部署（任务记录、部署与插件），最下面是上手指南。侧栏顶部可以切换当前项目，工作台和批量处理都会套用它的方案。

### 上手指南

第一次打开时自动进入，之后从侧栏随时回来。上面是准备清单，实时显示处理服务、NER、大模型、浏览器插件和项目是否就绪，缺什么直接跳到对应设置；中间带着用示例走一遍识别、复核、改稿、导出；下面是三种脱敏方式的对照和常见问题。

### 工作台

- **输入**：粘贴文本，或导入 TXT、Markdown、CSV、JSON、Word、PDF；内置三段虚构示例（中英混合访谈、客服记录、英文邮件）。
- **处理方案**：三种脱敏方式各带一句实时示例；“轻 / 标准 / 强”三档力度；识别范围按实体类型勾选；用一句话写要求（如“保留北京的地名，上海的地名隐去”），可先预览系统的理解；更多设置里有语言、待确认实体的处理、部署方式和额外隐去词。
- **识别轨迹**：规则层、NER 层、大模型核查、合并与脱敏四段，各显示命中数与耗时，点哪一层就只看这一层的结果。
- **原文与结果对照**：两侧高亮联动，掩码显示为墨条，替换和泛化的词带下划线；结果栏可直接切换方式和力度；“三种方式对照”并排比较后一键采用。
- **逐条复核**：按待确认、人工、已恢复筛选，搜索，`J` / `K` 切换，`A` 确认、`R` 恢复原文；同名实体可一起处理；可改类型、单独换方式、指定替换词、查看知识图谱层级、调整标记范围、补充遗漏。
- **最终稿**：可自由修改任意位置，自动保存为新版本，支持撤销重做、查找替换和与自动结果对比。
- **导出**：导出 TXT、Word、处理报告和审计记录；导出前自动做一次隐私复检，发现残留的号码、已确认实体或职务身份会先提醒并可定位。

### 批量处理

选择多个文件或整个文件夹，先用几段样本试跑确认方案，再在后台处理全部文件。文档整份处理（超长时在段落处切开），同一文件里的编号和替换词一致；CSV 和 JSON 每行（条）一段，所有列都参与识别，列名作为识别线索。处理过程显示进度和实体分布，可以中途停止；完成后导出 ZIP（逐文件最终稿，CSV、JSON 还原成原来的列，附清单）、结果表 CSV、处理清单 JSON，也可以逐个打开任务复核。文本编码自动识别 UTF-8、GBK 和 UTF-16。

### 人工复核

集中处理所有任务里置信度不足或识别层判断不一致的实体，可按类型筛选，确认结果同步回对应任务，并能直接在工作台打开。

### 项目与规则库

- 项目保存一类材料的完整方案：脱敏方式、力度、识别范围、保留词、自然语言要求、部署方式，以及只在该项目生效的自定义规则。
- 规则库管理全局规则：固定词或正则表达式，边写边用后端引擎试匹配；提供学号、工号、车牌号、病历号、统一社会信用代码等 11 个常用模板；可按实体类型分别设置脱敏方式。

### 任务记录、部署与插件

- 任务记录可按原文、结果或任务号查找（在服务端查，覆盖全部任务），筛选、重新打开或删除，可按天数清理；操作记录只保存位置、长度和带本机密钥的哈希，不保存明文。
- 部署与插件页显示各识别引擎的状态，在这里选择本地和云端的大模型（见“接入大模型”），给出 NER 模型的安装方法和浏览器插件的安装步骤。

## 识别与脱敏

| 环节 | 实现 |
|---|---|
| 规则层 | 手机号、国际电话、邮箱、身份证（校验位）、银行卡（Luhn 校验）、护照号，全角数字和夹着零宽字符的号码也能识别；项目与全局自定义规则（正则匹配有超时保护） |
| NER 层 | 安装多语种 NER 模型（见“接入 NER 模型”）后与内置轻量识别器同时运行；未安装时只用轻量识别器（姓名、机构、地点、地址） |
| 隐性隐私 | 单独的识别器找出“心内科主任”“财务处处长”这类部门加职务的组合，标为“职务身份”，交给人工确认 |
| 大模型核查 | 置信度低于 90% 的实体送 OpenAI 兼容接口复核，并补充遗漏；补漏结果按原文全部出现位置落地，原文中不存在的串不采纳；调用失败自动降级 |
| 合并 | 偏移校验、去重、冲突消歧，同名实体在全文补全 |
| 掩码 | `【PERSON-001】` 形式，同一实体全文编号一致 |
| 差分隐私替换 | 按指数机制从同类候选中抽取替换词（大学换大学、医院换医院、科室职务换同领域职务）；ε 轻 4、标准 1、强 0.25，ε 越小越随机 |
| 知识图谱泛化 | 沿上位概念上溯，力度决定上溯层数，例如“北京协和医院 → 北京某医院 → 医疗机构”；内置 213 条实体与行政区划，英文句子给出英文概念；可选远程 CN-Probase / CN-DBpedia，默认关闭 |

实体类型共 11 类：姓名、机构、地点、详细地址、电话、邮箱、身份证号、银行卡号、护照号、职务身份、自定义。

## 浏览器插件

`browser-extension/` 是 Manifest V3 插件，连接本机的墨隐服务：

- 在 ChatGPT、豆包、Kimi 等对话框里选中文字，右键“用墨隐脱敏并替换”或按 `Alt + Shift + M`，文字原地换成脱敏结果，`Ctrl + Z` 可撤销；对话框在 iframe 或 Shadow DOM 里也能用；
- 等待结果期间如果改了输入框里的内容，插件不会替换，并提示重新选中；
- 选中网页文字后在弹窗里切换方式与力度、查看高亮结果、修改、复制或导出；
- 每次处理保存为任务，可一键在工作台继续复核；设置里选了项目时，使用该项目的整套方案。

安装：Chrome 或 Edge 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开开发者模式，点“加载已解压的扩展程序”，选择 `browser-extension` 文件夹。详见 [browser-extension/README.md](browser-extension/README.md)。

## 接入大模型

大模型是可选的：不接也能完整使用，置信度不足的实体交给人工确认。接入后它会复核这些实体、补充遗漏，并理解用一句话写的要求。

在“部署与插件”页的“大模型与部署方式”里设置，保存后立即生效，不用改配置文件、不用重启：

- **本地模型**：选 Ollama、LM Studio、vLLM 或其他 OpenAI 兼容接口，地址自动填好；点“读取模型列表”列出这台电脑上已有的模型。页面上有按内存、显存选模型大小的建议，例如 16 GB 内存可以用 `ollama pull qwen3:8b` 下载的 8B 模型。
- **云端模型**：选 DeepSeek、阿里云百炼（通义千问）、月之暗面 Kimi、智谱 GLM、硅基流动、火山方舟（豆包）、OpenAI 或其他兼容接口，填密钥后读取模型列表或直接填写模型名。处理方案的部署方式选“云端”时生效，只发送需要核查的句子。

两边都可以先“测试连接”。密钥保存在本机数据库里，接口只回显尾号。没有在网页里设置过的一侧沿用 `backend/.env` 里的 `PRIVSHIELD_LLM_*` 配置；多人共用的服务器可以在 `.env` 里设 `PRIVSHIELD_MODEL_SETTINGS_EDITABLE=false`，只允许管理员改。

GPU 服务器：`cp .env.example .env` 后 `docker compose --profile gpu up -d --build`，同时启动前端、后端和 vLLM（默认 Qwen3-14B-AWQ，可在 `.env` 中改 `VLLM_MODEL`）。服务器部署默认由 Nginx 在 `http://服务器IP:8080` 提供前端，建议只开放这一个端口。健康检查：`curl http://127.0.0.1:8080/api/v1/health`。

## 接入 NER 模型

NER 层默认使用内置的轻量识别器。安装多语种模型 Davlan/xlm-roberta-base-ner-hrl（约 1.1 GB，CPU 即可运行）后，姓名、机构、地点由模型和轻量识别器共同识别：

- Windows：先运行过一次 `启动墨隐.cmd`，再双击 `scripts\安装NER模型.cmd`；
- macOS / Linux：在项目根目录运行 `backend/.venv/bin/python scripts/setup_ner.py`。

脚本会安装 PyTorch 和 Transformers，从魔搭社区下载模型（失败时改用 Hugging Face 镜像和官网），试运行一次，再在 `backend/.env` 中开启 NER（其他配置原样保留）。完成后重启后端，“部署与插件”页的 NER 层会显示模型名。模型加载失败时识别照常进行，页面上会显示原因。

## 使用边界

- 差分隐私替换对“从候选中抽取替换词”这一步使用指数机制，ε 可配置；整段文本端到端的差分隐私保证没有形式化证明，论文与答辩中按此表述。
- 远程知识图谱和云端大模型默认关闭，开启后会把实体词或待核查句子发送到所配置的服务，只应连接可信服务。
- Word 和 PDF 只提取文字处理，不做扫描件 OCR，也不重建原版式。
- 多语种效果以冻结测试集的评测结果为准。
