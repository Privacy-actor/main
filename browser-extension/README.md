# 墨隐浏览器插件

立项书中“浏览器插件 + 本地服务”的插件部分。插件只连接你自己部署的墨隐服务（默认 `http://127.0.0.1:8000`），不调用任何第三方接口。

## 安装

1. 先启动墨隐（Windows 双击项目根目录的 `启动墨隐.cmd`，或在 `backend` 目录下运行 `python -m uvicorn app.main:app --port 8000`）；需要“去工作台复核”时也要启动前端。
2. Chrome 或 Edge 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开“开发者模式”。
3. 点“加载已解压的扩展程序”，选择本目录 `browser-extension/`。
4. 服务地址不是默认值时，在插件的“设置”里修改后点“测试连接”（漏写 `/api/v1` 会自动补上）；非本机地址会请求一次访问授权。

## 四种用法

- **对话框里一键脱敏**：在 ChatGPT、豆包、Kimi 等网页的输入框里写好内容，选中文字后右键“用墨隐脱敏并替换”，或按 `Alt + Shift + M`。页面底部先提示“正在脱敏”，完成后选中的文字原地换成脱敏结果，`Ctrl + Z` 可撤销。没有选中时处理整个输入框。输入框在 iframe 或 Shadow DOM 里也能用。等待结果期间如果改了输入框里的内容，插件不会替换，并提示重新选中；连按两次只处理一次。
- **网页文字随手处理**：选中网页上的文字，右键“用墨隐脱敏选中文本”，或点工具栏图标。弹窗里可以切换掩码、差分隐私替换、知识图谱泛化和三档力度，查看高亮结果，修改后复制或导出 TXT。
- **把大模型的回答还原成原文**：大模型回复后，选中它的回答，右键“用墨隐还原选中文字”；也可以把回答粘贴到弹窗里点“还原回答”。回答里的 `【PERSON-001】`（写成 `PERSON_001`、`[PERSON-001]` 也认）和差分隐私替换词会换回原文并高亮，点“复制还原结果”即可。对照的是最近 20 次用插件脱敏的任务，最近一次优先；同一个编号在几次脱敏里指不同的人时按最近一次还原并注明。插件只记任务编号，不存文字。
- **和工作台连通**：插件里的每次处理都保存为任务，修改会自动保存为最终稿新版本；需要逐条复核时点“去工作台复核”。在设置里选择项目后，插件使用该项目的整套方案（方式、力度、识别范围、保留词、自定义规则），弹窗里临时改方式或力度只影响那一次；项目在网页里被删除后，插件改用临时方案并提示。

## 文件

| 文件 | 作用 |
|---|---|
| `manifest.json` | 权限、右键菜单、快捷键 |
| `shared.js` | 设置读写、接口调用（带超时和中文错误说明）、项目方案、实体名称和颜色、最近脱敏的任务编号与还原回答 |
| `service-worker.js` | 右键菜单与快捷键：找到正在输入的框架，一个标签页同一时间只处理一段 |
| `page-tools.js` | 注入页面的工具：读取选区并记下位置，写回前核对内容，页面提示条 |
| `popup.*` | 工具栏弹窗 |
| `options.*` | 设置页：服务地址、项目、默认方式与力度 |
| `icons/` | 印章图标 |

插件读取的是网页上可见的文字，不处理图片，也不会读取网页的账号或 Cookie。浏览器自己的设置页、扩展商店等页面不允许插件读取，按快捷键时插件图标上会显示感叹号。
